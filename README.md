# BorrowBook 📚

## Offline Personal Book Lending Management Application

BorrowBook is a React Native mobile application that helps users manage personal book collections and track books lent to others.

## Features

- Add new books
- View available books
- Edit book information
- Delete books
- Lend books to borrowers
- View borrowing records
- View borrowing details
- Mark books as returned
- Offline data storage using SQLite

## Technologies Used

- React Native
- Expo
- JavaScript
- SQLite
- React Navigation

## Installation

1. Clone this repository.
2. Run `npm.cmd install`.
3. Run `npx.cmd expo start`.
4. Scan the QR code using Expo Go.
